Mode Toggle — one document, three adapters

Demo-page test case — NOT expected real-world behavior. No production app would serve the same document through three switchable adapter modes on one URL. This page exists to exercise and compare the three adapter surfaces (SSR / client / markdown) against the SAME feature-matrix document and the SAME shared harness, so their contracts can be inspected side by side in one place.

The same feature-matrix document rendered through the SSR, client, and markdown adapter modes. Click a mode — the server reloads the page for that mode (full SSR HTML in the response body in SSR mode; raw source embedded in markdown mode). The shared harness below asserts the exact feature-matrix checks in every mode, plus the mode-specific ones.
