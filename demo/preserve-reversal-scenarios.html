preserve-reversal-scenarios — the preserve-by-reversal demo (Feature 4)

The preserve-by-reversal flag (Feature 4, docs/specs/handoffs-review-9.md D1-D8): a layerApply mint with preserveByReversal:true makes origin-owned nodes reverse as authored edits (not excluded). The whole-subtree cascade (D2) threads the preserved context through nodeToLegacy so descendants ship too. The flag is a reverse-time projection (D3) — the node stays minted, distinct from promotion. A layer replacement drops the flag (D4) — a same-hookName rows-mint replaces the layer flag-less, so the re-minted rows are then excluded. The banner is preserve-reversal-scenarios; the profile line is [preserve-reversal:profile].
