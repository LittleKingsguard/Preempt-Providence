hooks-scenarios — the value-provider slot (SPA scenarios)

Three real-world scenarios driving the HOOKS contract (docs/specs/hooks-map-review.md §7 — the value-provider slot): a theme switcher, a user/session panel, and a live counter/badge. Each card's controls are authORED buttons whose function-STRING click bodies write hooks.<name> through clientAPI.apply (the managed channel — never direct node access); the source→target cascade repopulates the consumer readouts. The runner checks assert the write → cascade → rendered-output chain and pin the USER CONTRACT: N writes land ONE deterministic hook-<name> replace-in-place layer (the layer stack stays O(1)). The banner is hooks-scenarios; a profile line ([hooks-scenarios:profile]) mirrors the other pages' acc() instrumentation.
